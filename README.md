# DinoLarp
DinoLarp adalah rekreasi ulang dari Dinosaur Game di browser dengan sedikit perbedaan fitur.

# Control:
- 'A' dan 'D' = bergerak horizontal ke kiri dan ke kanan
- 'Space' = bergerak vertikal atas (jump)

# Fitur:
- Player movement = Dino dapat bergerak ke kanan dan ke kiri, serta melompat.
- Collision = Dino dapat lompat jika bersentuhan dengan collision ground dan game over jika Dino bertabrakan dengan collision cactus.
- Main menu = Pada main menu terdapat dua tombol, "Start Game" dan "Quit".
